## 每周固定节奏

- [ ] 周一：查看课程反馈、失效来源和上周漏斗。
- [ ] 周二至周三：精修 2 节课或更新 1 节前沿课。
- [ ] 周四：完成本周主内容和渠道原生改写。
- [ ] 周五：发布并回复具体问题。
- [ ] 下周一：记录 72 小时结果，只改变一个变量。

## 每节课发布门槛

- [ ] 评分 ≥85，且没有来源、事实、实践或移动体验硬伤。
- [ ] 看前问题、精确观看范围和看后任务完整。
- [ ] 至少一个最小实验或推导、一个失败反例、一个可检查产物。
- [ ] 自测与掌握门能区分“看懂”和“独立完成”。
- [ ] 中英内容、国内/国际入口、320/390/768/1440px 已核验。
- [ ] 一手来源、核验日期和变更摘要已记录。

## 新课程准入

- [ ] 同一需求被真实提出至少 3 次，或填补明确先修断层。
- [ ] 至少两个一手来源，且不与现有课程重复。
- [ ] 有可运行实验、可检查产物和掌握门。
- [ ] 国内/国际来源与版权策略明确。
- [ ] 有复核日期和维护责任。
